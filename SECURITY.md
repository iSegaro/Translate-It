# Security Policy

We take the security of Translate It seriously and appreciate reports that help keep the project and its users safe.

## Reporting a Vulnerability

Please report sensitive security issues **privately** using GitHub Private Vulnerability Reporting:

- **[Report a vulnerability](https://github.com/Translate-It-App/Translate-It/security/advisories/new)**
- Repository Security page: https://github.com/Translate-It-App/Translate-It/security

Please do **not** disclose vulnerability details through public GitHub Issues, Discussions, or Pull Requests. Ordinary bugs without a security impact can be reported through the normal [Issue tracker](https://github.com/Translate-It-App/Translate-It/issues).

A useful report includes, where available:

- the affected version or release;
- the impact and what an attacker could do;
- clear reproduction steps;
- any relevant technical details, logs, or proof-of-concept information.

## Supported Versions

The project focuses on maintaining its current stable release. Security reports are assessed against the latest release. There is no commitment to provide maintenance or security fixes for historical releases.

## Response and Disclosure

Reports are reviewed by the project maintainers. Response and remediation timelines depend on the nature and severity of the report, so fixed deadlines are not guaranteed.

Please coordinate any public disclosure with the maintainers, and allow time for the issue to be assessed and addressed before sharing details publicly. We are not able to offer a bug bounty program or monetary rewards for reports.
